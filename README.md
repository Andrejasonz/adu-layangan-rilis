# Adu Layangan – Rilis

Game LIVE TikTok interaktif dari **Saffron Kite Games**: penonton saling adu layangan lewat komentar, like, dan gift.

- Halaman produk & panduan: https://games.saffronkite.com/adu-layangan/
- Unduh versi terbaru: lihat **Releases** di repo ini (`AduLayangan-Setup-x.y.z.exe`, Windows 10/11 64-bit).

Repo ini hanya berisi file rilis dan proses build otomatis. Kode sumber tidak dipublikasikan.

**Catatan:** installer belum bertanda tangan digital, jadi Windows SmartScreen mungkin menampilkan peringatan → klik *More info → Run anyway*. Aplikasi hanya membaca event LIVE publik dan tidak pernah meminta password TikTok.
